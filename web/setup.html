Set up QuizMe

Takes about 3 minutes on your iPhone. After that, opening Instagram shows you a CS question first, and you get in once you answer it correctly.

1 Add the “QuizMe Gate” shortcut

When Instagram opens, this shortcut checks whether you just answered a question. If you didn’t, it sends you to the quiz.

Get “QuizMe Gate”

Build it yourself

In the Shortcuts app tap +, name it QuizMe Gate, and add these actions in order:

  1. Get File: from Shortcuts folder, path quizme_unlock.txt. Turn Error If Not Found off.
  2. If File has any value
  3. Inside the If: Get Details of Files: Last Modified Date of File
  4. Inside the If: Get Time Between Dates: between Last Modified Date and Current Date in Seconds
  5. Inside the If: another If Time Between Dates is less than 30 containing Stop This Shortcut
  6. After both End Ifs: Format Date: Current Date, Date Format Custom, format string yyyyMMddHHmmss
  7. URL: the address below, followed by the Formatted Date variable: https://…/?s=
  8. Open URLs: URL

2 Add the “QuizMe Unlock” shortcut

When you answer correctly and tap Continue to Instagram, this shortcut records the unlock and opens Instagram.

Get “QuizMe Unlock”

Build it yourself

Name it exactly QuizMe Unlock. Capitalization matters. Add these actions:

  1. Text: unlocked
  2. Save File: save Text to the Shortcuts folder. Turn Ask Where to Save off, set Subpath to quizme_unlock.txt, and turn Overwrite If File Exists on.
  3. Open App: Instagram

3 Create the automation

Apple doesn’t let anyone share automations, so this step has to be done by hand.

  1. Open Shortcuts and go to the Automation tab. Tap + (or New Automation).
  2. Choose App, then tap Choose and select Instagram.
  3. Keep Is Opened checked and Is Closed unchecked.
  4. Select Run Immediately and turn Notify When Run off. Tap Next.
  5. Pick QuizMe Gate. If it isn’t listed, choose New Blank Automation, add Run Shortcut, and select QuizMe Gate.

4 Test it

  1. Open Instagram. You should land on a QuizMe question in Safari.
  2. Answer it. Tap Continue to Instagram, then Open when Safari asks.
  3. Instagram opens. Close it and open it again, and you get a new question.

The first time, Shortcuts may ask permission to read the file or open the website. Choose Always Allow.

Troubleshooting

  • Instagram opens and the quiz comes right back (loop): the unlock isn’t being seen. Check that “QuizMe Unlock” saves to the same file name (quizme_unlock.txt) in the Shortcuts folder that “QuizMe Gate” reads.
  • The quiz never appears: make sure the automation is on and set to Run Immediately. In “QuizMe Gate”, add Show Result after Get Time Between Dates and run it by hand. You should see a positive number. If it’s negative, swap the two dates.
  • “Continue to Instagram” does nothing: the unlock shortcut must be named exactly QuizMe Unlock.
  • Too many Safari tabs: go to Settings → Apps → Safari → Close Tabs and choose After One Day.
  • Need a break from QuizMe? In Shortcuts → Automation, turn the Instagram automation off.
